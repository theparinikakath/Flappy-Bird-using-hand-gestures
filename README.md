# Flappy Bird using Hand Gestures 🐦✋

Experience the **classic Flappy Bird** in a completely new way — controlled with **hand gestures** instead of a keyboard! This innovative Python-based game uses real-time **computer vision** to track your hand movements, creating a fun, interactive, and accessible gameplay experience.

---

## 🎮 Game Description

Control the bird by **raising or lowering your hand** in front of your webcam — no keyboard required! This game was built as a part of a **DRID Project** during the **Summer Internship at JIIT, Noida**, and integrates **machine learning**, **OpenCV**, and **MediaPipe** for gesture recognition.

---

## ✨ Key Features

- ✋ **Hand Gesture Control**  
  Move the bird up and down by moving your hand — accurate and real-time control with no physical buttons.

- 🧠 **Computer Vision Integration**  
  Uses **OpenCV** and **MediaPipe** for smooth hand tracking and gesture detection.

- 🕹️ **Classic Flappy Bird Mechanics**  
  Fly the bird through pipes without crashing — simple to play, hard to master!

- 📢 **Real-time Feedback**  
  Immediate visual and audio feedback based on your gestures for a responsive experience.

- ⚙️ **Customizable Settings**  
  Tweak gesture sensitivity, game speed, and difficulty to suit your skill level.

- 🏆 **High Score Tracking**  
  Challenge yourself or compete with friends to achieve the highest score.

---

## 🛠️ Technologies Used

- **Python**: Core programming language
- **OpenCV**: For capturing webcam input and image processing
- **MediaPipe**: For hand landmark detection
- **Pygame**: To build the game and handle graphics, animations, and sounds

## 🧑‍💻 Installation Instructions

> 💡 Make sure you have Python installed on your system.

1. **Clone the repository**

   ```bash
   git clone https://github.com/theparinikakath/Flappy-Bird-using-hand-gestures.git
    ````

2. **Install dependencies**

   ```bash
   pip install -r readme.txt
   ```

3. **Run the game**

   ```bash
   python main.py
   ```

4. Allow webcam access and start moving the bird with your finger!
